欢迎使用 Health Panel

100% 本地离线 · Apple Health 风格健康看板

正在检测本机同步状态…
  1. 1. 授予 Root 权限

    在 KernelSU 或 Magisk 中允许本应用使用 Root 权限，以便安全读取本机华为运动健康数据库快照。

  2. 2. 首次打开一次华为运动健康

    首次恢复加密密钥需先打开「华为运动健康」等待手表数据刷新片刻，切回本面板即可自动完成解密与解析。

  3. 3. 自动同步 · 长下拉增量刷新

    每次打开应用自动检测更新；在顶部页面向下长拉至绿环亮起后松开，可随时触发快速增量刷新。

  4. 4. 本地加密与按需联网

    密钥通过 Android Keystore 加密存储于本机，健康数据全程离线解析不上传（仅训练轨迹加载高德底图时联网），也可在「更多」中手动导入数据库。
